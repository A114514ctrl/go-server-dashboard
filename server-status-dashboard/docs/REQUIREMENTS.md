# 监控大屏项目需求文档 (v1.0)

## 一、 项目概述

**1. 项目名称**：Server Status Dashboard（轻量级服务监控大屏）

**2. 项目背景**：开发者和运维人员需要一个直观、极简的面板，用于实时查看服务器自身的硬件资源占用情况，以及外部依赖服务（如网站、API、数据库）的存活状态。

**3. 核心目标**：实现一个单文件部署、开箱即用、具有“黑客帝国/极客风”视觉体验的实时大屏。

------

## 二、 核心功能需求

### 2.1 硬件资源实时监控 (System Metrics)

系统需要实时读取宿主机的硬件状态，并转换为易于理解的百分比和数值。

- **CPU 监控**：总体使用率（%）、核心数。
- **内存监控**：总内存（GB）、已用内存（GB）、内存使用率（%）。
- **磁盘监控**：根目录（`/`）的总容量、已用容量、存储使用率（%）。
- **运行时间**：服务器已连续运行的时间（Uptime）。

### 2.2 外部服务连通性检测 (Service Health Check)

系统能够根据配置好的 URL 列表，定时发起 HTTP/Ping 请求，检测服务是否存活。baidu.com,taobao.com.google.com

- **状态展示**：正常（Green / 200 OK）、异常（Red / Timeout 或 50x 错误）。
- **延迟展示**：记录请求的响应时间（如 `45ms`）。

### 2.3 前端大屏展示 (Dashboard UI)

- **深色模式**：默认采用全局深色背景（Dark Mode），辅以高亮色的进度条。
- **自动刷新**：页面无需手动刷新，通过 JavaScript 定时器（Polling）每隔 1 秒静默拉取最新数据并更新视图。

## 三、 技术栈选型

| **模块**       | **技术选型**                 | **选用理由**                                                 |
| -------------- | ---------------------------- | ------------------------------------------------------------ |
| **后端框架**   | Go + Gin                     | 路由简单，性能极高，最后可编译成单一二进制文件。             |
| **系统数据**   | `shirou/gopsutil`            | Go 语言中最权威的系统信息收集库，API 极其友好。              |
| **前端 UI**    | HTML + CDN 引入 Tailwind CSS | 零构建配置，直接在 HTML 里写 class 就能实现极美观的现代 UI。 |
| **前后端通信** | 原生 Fetch API               | 轮询（Polling）机制，比 WebSocket 简单，半小时即可调通。     |

------

## 四、 API 接口设计 (后端契约)

后端只需提供两个核心的 RESTful GET 接口。

### 接口 1：获取系统硬件状态

- **路径**: `GET /api/system`
- **响应格式**: JSON
- **响应示例**:

JSON

```
{
  "code": 200,
  "data": {
    "cpu_percent": 24.5,
    "cores": 4,
    "memory_total_gb": 16.0,
    "memory_used_gb": 8.5,
    "memory_percent": 53.1,
    "disk_percent": 68.2,
    "uptime_hours": 124
  }
}
```

### 接口 2：获取外部服务状态

- **路径**: `GET /api/services`
- **说明**: 后端在内存中维护一个关注列表（如 Github、Google、自建博客），并发检测后返回结果。
- **响应示例**:

JSON

```
{
  "code": 200,
  "data": [
    {
      "name": "My Personal Blog",
      "url": "https://blog.example.com",
      "status": "up",
      "latency_ms": 42
    },
    {
      "name": "Database API",
      "url": "http://127.0.0.1:3306",
      "status": "down",
      "latency_ms": 0
    }
  ]
}
```
